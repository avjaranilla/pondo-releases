Install in 3 steps

  1. Tap Download Pondo above. If Chrome asks, tap Download anyway.
  2. Open the file from the notification, or from Chrome's ⋮ → Downloads.
  3. Tap Install. If Android asks first, tap Settings, turn on Allow from this source, go back and tap Install.

If Play Protect warns about an unknown app, tap More details → Install anyway. It warns because Pondo isn't from the Play Store.

After this, Pondo updates itself. Already have Pondo? Install over it to update and your data stays. Never uninstall: that deletes your data.
